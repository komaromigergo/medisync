# MediSync – interaktív demó

Az OTIO projekt demóalkalmazása: orvosi, beteg- és patikanézet, gyógyszerfelírás ütközés-ellenőrzéssel és patikai cserével.

- Gyógyszeradat: OGYÉI törzskönyvi lista (feldolgozás: `scripts/build_data.py`)
- Adatok és betegek szintetikusak; oktatási prototípus, nem orvosi eszköz.
- A DÁP, az ujjlenyomat, az e-személyi chip és az EESZT-értesítés szimuláció.

Futtatás: `npm install && npm run dev`
